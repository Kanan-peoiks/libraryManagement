# 📚 Library Management System REST API

Bu layihə **Library Management System** üzrə Spring Boot 3 istifadə edərək hazırlanmış RESTful API xidmətidir. Layihədə Müəlliflər (`Author`), Kitablar (`Book`) və Üzvlər (`Member`) üzrə CRUD əməliyyatları, Səhifələmə (Pagination), Çeşidləmə (Sorting), Xəta idarəetməsi (Exception Handling) və Unit testlər tətbiq olunub.

---

## 🛠️ İstifadə Olunan Texnologiyalar

* **Java 17 / 21**
* **Spring Boot 3**
* **Spring Data JPA (PostgreSQL)**
* **Lombok & Jakarta Validation**
* **Springdoc OpenAPI (Swagger 3)**
* **JUnit 5 & Mockito (Unit Testing)**
* **Gradle / Maven**
